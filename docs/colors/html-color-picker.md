# HTML Color Picker

## URL
/tools/colors/html-color-picker

## Formatos
HEX, RGB, RGBA, HSL, HSLA, OKLCH, OKLab, nomes CSS.

## Funcionalidades
- Input color.
- EyeDropper (lupa).
- Preview.
- Sliders.
- Contraste.
- Shades/tints.
- Histórico.
- Favoritos.
- Copiar.

## Contraste
Black text (X:1 👍/👎)
White text (X:1 👍/👎)
AA/AAA indicadores.

## Acessibilidade
Labels, foco, ARIA live, teclado.
