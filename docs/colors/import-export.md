# Importação e exportação

## Imagem
- Upload local (Canvas).
- Usuário escolhe 5, 7, 9 ou 11 cores.
- Median cut com opção OKLab.
- Permitir salvar direto.
- Importar por URL de imagem.

## JSON
- Importar Figma Tokens.
- Importar Style Dictionary.
- Importar paleta JSON.

## Exportação
- Individual por cor.
- Paleta completa.
- Protótipo PNG 1x/2x.
- Protótipo SVG.
- Paleta como imagem tipográfica (horizontal, vertical, card).
