# Fases para Claude Code
F0 auditoria: ler docs e estrutura real; dependências, quota/rotas/policies/conversões; apontar conflitos e propor plano, sem código.
F1 motor: modelo de tokens, parâmetros numéricos documentados, biblioteca/licença, gamut, famílias de feedback e fixtures. Apresentar calibração e só implementar após aprovação. Funções puras e testes.
F2 UI: registro Colors, picker reutilizado, quatro estratégias, claro/escuro/comparação, i18n e acessibilidade.
F3 edição: bloqueios, secondary manual, AA/AAA, ajustes explícitos, avisos e snapshot.
F4 dados: quota conjunta, privado padrão, duplicação, rascunho/login, arquivo/restauração/exclusão, downgrade, viewer e protótipos.
F5 exports: MD/CSS/ZIP, prefixos/escopo/data-theme, fallback, avisos e auth.
F6 aceite: matriz requisitos/testes, regressão, build, runbook, atualização de docs.
Cada fase exige plano de arquivos e testes aprovado, implementação pequena, revisão e parada. Não avançar automaticamente.
